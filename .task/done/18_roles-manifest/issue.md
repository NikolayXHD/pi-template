# 18 — roles.json: роль по умолчанию и список доступных ролей

## Контекст

Расширение `extensions/roles` держит режимные роли: markdown-файл активной
роли дописывается в конец system prompt (`before_agent_start`), переключение —
`/role <name>`, Ctrl+R и флаг `--role`. Сейчас у расширения две жёсткие
границы:

- Роль по умолчанию зашита в код (`DEFAULT_ROLE = "develop"`,
  `extensions/roles/index.ts`): старт без `--role` всегда даёт develop.
- Набор ролей — это содержимое `roles/*.md`: все найденные файлы равнодоступны
  в цикле и в `/role`, отключить роль без удаления файла нельзя.

@NikolayXHD предложил манифест `roles.json` с тремя ключами — `default`,
`enabled`, `disabled` — и синхронизацию манифеста с файловой системой в
`make materialize`: файл появившейся роли уходит в `enabled`, файл пропавшей —
в `disabled`.
