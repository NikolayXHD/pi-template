# 22 generalized-template-variables

## Постановка (@NikolayXHD, после коммита e2e49f7 «roles: handlebars templates»)

Роли переведены на Handlebars. Следующий шаг — растворить понятие роли
в механизме шаблонов:

- роль — просто строковая переменная; конфиг объявляет переменные
  (`role`, `vllm`, любые другие) с множеством допустимых значений;
- выбор файла роли выражается не кодом расширения, а шаблоном
  `{{#if (eq role "x")}}{{> x.md}}{{/if}}`;
- меню позволяет выбрать значение любой переменной на текущую сессию;
- переменные делятся на машинные (текущее значение в конфиге, сессия
  наследует и может переопределить, глобально — только правка конфига)
  и сессионные;
- scope шаблонизатора расширяется: скилы, глобальный и проектный
  AGENTS.md, кастомные промпты, промпты агентов в `~/.pi/agent/agents`;
- материализация для observability: путь к копии содержит только те
  переменные, которые упомянуты в шаблонах данного файла, а не все
  существующие.

Инструкции — направления мышления, не спецификация; улучшения и
упрощения обсуждаются.
