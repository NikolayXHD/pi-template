## Стадии (порядок фиксирован)

**D.0. Бэкап.** Скопировать мигрируемые файлы живого каталога (список
ниже) в `.task/current/23_template-implementation/4_migration/backup/`,
сохраняя структуру. Без бэкапа дальше не двигаться.

**D.1. Миграция источников** (`/home/kolia/.pi/agent`):

- `roles.json` → `template.json`:
  `{"vars": {"role": {"values": {"shell": <перечень файлов ролей без
  расширения>}, "initial": "preflight"}}}`; `default` и `cycle` уходят.
  Команда `values` должна давать только файлы ролей `roles/*.md`, без
  каталогов; конкретная форма — на усмотрение.
- `AGENTS.md` → `AGENTS.md.template`; в конец файла добавить строку
  `{{> (concat "roles/" role ".md")}}` (прежняя механика дописывала роль в
  конец системного промпта — сохранить ближайшее поведение).
- `SYSTEM.md`, `APPEND_SYSTEM.md` → `*.template` без изменения содержимого.
- `skills/*/SKILL.md` → `SKILL.md.template`; `prompts/*.md` →
  `*.md.template`; `agents/*.md` → `*.md.template`.
- `roles/**` не трогать (это партиалы), кроме `roles/materialized/` —
  удалить.
- `.gitignore`: добавить генерируемые зеркала (`AGENTS.md`, `SYSTEM.md`,
  `APPEND_SYSTEM.md`, `skills/*/SKILL.md`, `prompts/*.md`, `agents/*.md`).
- Сгенерировать зеркала первым рендером тем же кодом движка
  (одноразовый скрипт, в пакет не включать); проверить: сырых тегов
  `{{…}}` в зеркалах нет, YAML шапок скилов валиден.

**D.2. Пакет:** `package.json` — имя `pi-template`; проверить manifest
пакета (pi-manifest для discovery) на имя и точку входа. Перенести
живые проверочные скрипты зон B и C (сейчас во временных каталогах) в

`template.json` (поля `values`/`initial`/`@`/`@<имя>`/`cwd`), синтаксис
шаблонов (включая `{{[var@]}}`, партиалы, двухэтапный рендер агентов),
`/template`, статусная строка, версии контекста. `TESTING.md` —
переписать под новый механизм: `node probe.mjs`, живые скрипты, ручные
сценарии.

**D.3. Готовность к публикации.** Push в GitHub и синхронизацию чекаута
`~/.pi/agent/git/github.com/NikolayXHD/pi-template` делает ведущий —
исполнитель останавливается на «готово».

## Ловушки

- Живой каталог агента не ломать: миграция — только переименования и
  добавления из списка; `.task/`, `sessions/`, `settings.json`, прочие
  файлы не трогать. Текущая сессия пользователя уже держит контекст в
  памяти — переименования её не рушат.
- Rollback — описать в отчёте: восстановление из `backup/` + откат
  переименований.
- `roles/snippets/**` и файлы ролей — не трогать.
- Erasable TS, без `any`; новые публичные имена не вводить.
- Коммиты не делать — в обоих репозиториях коммитит ведущий.
- Поиск — `git grep`, вне git — точечный `grep`; `find`/`rg` запрещены;
  toolTimeoutMs 120 с.

## Критерии приёмки

- Бэкап полон, rollback описан.
- Зеркала сгенерированы без сырых тегов; `template.json` разбирается
  движком (проверка скриптом), `role` получает список ролей, `initial` =
  `preflight`.
- `node probe.mjs` зелёный; живые скрипты в пакете запускаются и
  проходят.
- README/TESTING описывают фактическое поведение (сверить с design.md).
- Отчёт: перечень миграций (файл → файл), результаты проверок, rollback,
  вопросы.
