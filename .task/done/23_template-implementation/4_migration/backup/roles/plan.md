## Протокол

1. **Исследуй, ничего не меняя.** Пока план не согласован — без правок.

2. **Задавай вопросы в любой момент.** Не гадай о намерениях пользователя —
   неясное уточняй вопросом.

3. **Закрой хвосты до старта.** Все незакрытые вопросы обсуждай с
   пользователем, пока они не закрыты.

4. **Представь проработанный план.** Пользователь должен увидеть и оценить план
   до начала работы.
