# Правки дизайна по review-design.md

Исполнитель: helper-cloud-fast (продолжение ревью). Диспозиция ведущего;
править `design.md` и `interview.md` задачи 23 по пунктам ниже. В конце —
короткий раздел «Правки по ревью» в `review-design.md` (что применено).

## Major

1. **M1, имя команды.** В `design.md` протащить `/template` во все места
   («одна команда», зона C плана). В `interview.md` `/var` остаётся
   историческим именем — добавить в В13 строку: «`/var` в ранних записях —
   рабочее имя до В13».
2. **M2, два пути доставки.** Развести явно: основная доставка — точечная
   замена секций из памяти (старт сессии, кнопка); `/reload` — частный
   случай, где файлы перечитывает сама pi. Формулировку «минуя чтение
   файлов» как обобщение убрать. Лок ни в одном из путей не берётся.
3. **M3, старт сессии.** Назвать третий случай применения: старт сессии и
   сверка фактической модели — точечная замена секций на первом
   `before_agent_start`. Обоснование вписать коротко: pi читает зеркала до
   `session_start`, свой вариант сессия получает заменой секций; без неё
   первый ход увидит текст чужого view. То же — в «Версии контекста
   сессии» и «Пересчёт и применение».
4. **M4, база рендера под локом.** Рендер под локом (read tool, спавн,
   каталог) идёт view'ом применённой версии, не текущим; исключение —
   спавн: параметры спавна поверх применённых значений. Править места
   «своим view» / «под view сессии» и формулировку про ссылки в агентском
   файле.
5. **M5, детекция дочерней сессии.** Переписать «механизм детекции не нужен
   и не вводится»: своих механизмов не вводим, признак дочерней сессии —
   тег `<active_agent>` (запасной — имя сессии). Два отказа развести:
   тега нет — сессия не субагент, `@`-ключи не применяются; имя неизвестно
   — `@` применяется, `@<имя>` нет. В `interview.md` тезис «существующие
   механизмы её не дают» пометить опровергнутым
   `research-child-identity.md`.

## Minor

6. **m1, каталог advertised.** Зафиксировать ограничение: порядок
   обработчиков `session_start` между пакетами не гарантирован, чтение
   каталога асинхронное — каталог может держать прошлое зеркало до
   следующего обновления; «на каждом ходу» — только при активном
   инструменте `subagent`.
7. **m2, кандидаты контекста.** Полный перечень: `AGENTS.override.md`,
   `AGENTS.md`, `AGENTS.MD`, `CLAUDE.md`, `CLAUDE.MD`.
8. **m3, термины.** Добавить в «Термины» короткие статьи: «секции
   промпта», «точечная замена секций», «фикс-точка». «Автономная
   перерисовка» везде заменить на «перерисовка без спавна».
9. **m4, гигиена интервью.** Пункт В5 про линт-запрет `model@`/`level@` в
   шапке помечены снятым (В11); «Уточнение В6» → «Уточнение В5»; статус В9
   → «решено (пункт 1 — по итогам В10)»; блок В13 переместить после В12 —
   порядок В10, В11, В12, В13.
10. **m5, детекция правок исходников.** Механизм: сверка mtime+size
    источников на каждом `before_agent_start`, без пересчёта вычисляемых;
    правка перерисовывает актуальную версию и помечает контекст
    устаревшим.
11. **m6, переинициализация после `/reload`.** Рантайм расширения заменён,
    память потеряна; новый экземпляр принимает зеркала за применённую
    версию (диск — источник истины для применённого), актуальную рендерит
    заново.

## Nit

13. «Генерируемые `X` появляются…» — рядом со своими источниками (каталог
    агента или проекта), не только в рабочем дереве проекта.
14. «Потребители агентского файла — два» → два основных; строка, что
    preflight, slash-команды управления агентами и doctor читают те же
    зеркала атомарно.
