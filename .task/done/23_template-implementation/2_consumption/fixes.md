# Правки зоны B по кросс-ревью

Исполнитель: helper-cloud-fast (продолжение захода зоны B). Диспозиция ведущего
по `2_consumption/cross-review.md`; код — `/home/kolia/git/pi-template`, отчёт
— дописывание раздела «Правки по кросс-ревью» в `2_consumption/report.md`.
Коммиты не делать.

## Major

1. **Опознание секций SYSTEM/APPEND.** Замена молча не срабатывает, когда
   pi держит текст, прочитанный до нашего чтения зеркала (гонка с другой
   сессией, массовый случай — параллельные дети). Правило:
   - текст pi запоминать из `ctx.getSystemPromptOptions()` (фактически
     загруженный), не с диска;
   - секция наша, если источник, который pi выбрала, — наше зеркало
     (проектный `.pi/…` при trust, иначе агентский — по правилам pi);
   - источник-строка (ребёнок pi-subagents, SDK/CLI с явным промптом) — не
     заменять никогда; проверить по коду pi, видит ли расширение форму
     источника (`systemPromptSource` загрузчика или иначе); если различить
     нельзя — опознавать строку через идентичность ребёнка и текстовое
     совпадение с pi-стартом, а мисс опознания не замалчивать: громкое
     предупреждение.
2. **Приоритет модели/уровня при спавне — как у потребителя.** pi-subagents
   даёт явному параметру спавна приоритет над шапкой (`model-resolution`,
   суффикс `:level` над `agent.thinking`). Привести рендер к тому же:
   явный `model` (включая `:level`) → шапка YAML → дефолт сессии. Шапка
   при явном параметре не перекрывает его; `model@`/`level@` тела —
   фактические значения по этой же цепочке; фикст-точка при явном
   параметре сходится за один проход. Передавать в скобку признак «параметр
   явный», сейчас `preliminary` не различает параметр и дефолт.

## Minor

3. Ошибки ФС в скобках не должны валить `tool_call` и терять локи:
   исключения лока/записи — ловить, предупреждать, локи снимать в
   `finally`-порядке; поведение согласовать с `writeVersion` (предупреждение,
   не падение).
4. Снятие протухшего лока — атомарно: переименование каталога лока во
   временный и удаление; не удалось переименовать — кто-то уже занял, не
   трогать.
5. Повторный вход лока — по паре сессия+путь, не по процессу: родитель и
   foreground-дети одного процесса не должны делить глубину. Скоуп сессии
   передавать в API лока.
6. `thinking: true` — принимать как «уровень не задан» (как потребитель:
   `resolveEffectiveThinking` молча пропускает не-уровни), не бросать.
7. Замена записи скила обновляет и `name`, и `disableModelInvocation` из
   отрендеренного frontmatter.
8. identity: разбирать intercom-форму `subagent-<агент>-<runId>[-N]`;
   литерал `agent` не считать именем агента («имя неизвестно»).
9. Перечень источников дополнить корнями, которые читают потребители:
   `~/.agents` (агенты pi-subagents) и `.agents/skills` (у предков cwd и
   `~/.agents/skills`) — правило «при сомнении расширять».

## Nit

    предупреждение.
11. После двух неудачных попыток `lost` в скобке чтения — предупреждение,
    не молчаливое «читай прежнее».
12. Тесты: закрыть заявленный охват — `recompute`/`recomputeAll`/
    `computedAge`, замену SYSTEM/APPEND (не только добавление),
    `spawnPreliminary` с суффиксом `:level`, повтор после `lost`, запись
    отсутствующего зеркала, протухший свой лок, пропуск проектного скила
    без trust.
