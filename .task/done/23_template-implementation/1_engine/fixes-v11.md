# Правки движка по В11 — фикст-точка шапки агентского файла

Исполнитель: helper-cloud-fast (продолжение захода зоны A). Диспозиция —
`interview.md`, В11, и design.md, разделы «Агентский файл: два этапа» и
«Линт». Зона записи — `/home/kolia/git/pi-template`, отчёт — короткое
дописывание раздела «Правки по В11» в `1_engine/report.md`.

## Что сделать

1. Снять линт-запрет `model@`/`level@` (и форм с именем агента) в шапке
   агентского файла — В11 отменяет его.
2. Рендер шапки — итерациями до фикст-точки: первый проход с
   предварительными `model`/`level` (вход рендера), затем вычисляющая
   сторона извлекает модель и уровень из отрендеренной шапки и шапка
   перерендеривается с фактическими; останов — стабилизация текста шапки.
   Шов вызова извлечения (колбэк, резолвер или иное) — на усмотрение
   исполнителя; YAML-разбор остаётся вне движка.
3. Тело рендерится после стабилизации, с фактическими `model`/`level` в
   `@`-значениях — как сейчас.
4. Детект цикла: повтор уже виденной пары `model`/`level` при
   нестабильном тексте — ошибка рендера «модель шапки зависит от
   `model@`». Граничный предел числа итераций допустим как страховка.

Семантика (закрепить тестами): `model: {{[model@]}}` сходится к
предварительным значениям («та же модель»); осциллирующее выражение
(значение модели зависит от `model@` с чередованием) — ошибка.

## Тесты (probe.mjs)

- `{{[model@]}}` и `{{[level@foo]}}` в шапке получают фактические значения
  этапа 1;
- `model: {{[model@]}}` сходится к предварительной модели;
- осцилляция через `model@` в выражении модели — ошибка с ожидаемым
  сообщением;
- линт принимает `model@`/`level@` в шапке (таблица легальных форм);
  старые сценарии-отказы обновлены под новую семантику.

## Ловушки

- Проверять сходимость по стабилизации текста и повтору состояния, не по
  «числу проходов» в одиночку.
- Новых терминов не вводить: «фикс-точка» — из design.md.
- Стиль пакета прежний: erasable TS, без `any`, импорты с `.ts`.
- Коммиты не делать. Проверка — `node probe.mjs`, все сценарии зелёные,
  включая новые.
