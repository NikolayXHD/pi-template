# Правки зоны A по кросс-ревью

Исполнитель: helper-cloud-fast (продолжение захода зоны A). Диспозиция
ведущего по `1_engine/cross-review.md`; принятые находки — исправить,
остальное не трогать.

## Исправить

1. **minor, BOM.** `splitAgentSource` (`render.ts`) не снимает BOM и не
   нормализует переводы строк, в отличие от конвенции pi
   (`packages/coding-agent/src/utils/frontmatter.ts` в форке: stripBom,
   `\r\n` → `\n`). Файл агента с BOM сейчас молча уходит в тело. Снять
   BOM и нормализовать `\r\n` перед делением шапки. Сценарий: агентский
   файл с BOM рендерится двухэтапно так же, как без него.
2. **minor, ложное предупреждение.** Предупреждение «команда упоминает
   переменную, объявленную позже» не учитывает `@`-замещение: у субагента
   такая переменная не вычисляется, значение уже в окружении. Опираться
   на `isComputedVariable(spec, agentName)`, для чего пробросить
   `agentName` в `laterComputedReferences`. Сценарий: при `@`-ключе
   предупреждения нет.
3. **minor, таймаут и внуки.** Таймаут убивает только шелл (`sh -c`),
   фоновые команды переживают его. На POSIX — новая группа процессов
   (`detached`) и убийство группы по таймауту; win32-ветку оставить как
   есть, ограничение назвать в docstring. Сценарий: фоновый процесс,
   который писал бы маркер через 7 с, не переживает таймаут 5 с (маркер
   не появляется).
4. **nit, мёртвый код.** Удалить неиспользуемую `VARIABLE_SPEC_KEYS`
   (`vars.ts`).
5. **nit, единообразие.** В `computeView` заменить `name in implicit` на
   `Object.hasOwn` (как в `render.ts`).
6. **nit, молчаливый catch.** `collectQualifiedNames` (`render.ts`)
   молча глотает ошибку разбора — пробрасывать.
7. **nit, имена полей.** Поле `partials` несёт два смысла: в
   `LintContext` — путь источника (нужно лишь наличие), в
   `RenderContext`/`AgentRenderContext` — текст. Переименовать так, чтобы
   смысл был в именах: `LintContext` — `partialSources`, рендер-контексты
   — `partialTexts`; обновить `probe.mjs` под новые имена.
8. **nit, пустой список значений.** Успешная shell-команда без строк
   даёт `[]`; для динамического партиала это «резолвить нечем» — как и
   отсутствие списка. Приравнять пустой список к «без списка значений» в
   линте динамического партиала. Сценарий.
9. **nit, точность сравнений.** `assertEqual` в `probe.mjs` через
   `JSON.stringify` не различает `undefined` и отсутствующий ключ.
   Сравнивать `deepStrictEqual` поверх `canonicalize` (порядок ключей по-
   прежнему не значим).
10. **nit, строгость хелпера.** `makeExecutor` отвечает «успех с пустым
    stdout» на неизвестную команду — опечатка в тесте молча проходит.
    Бросать на команду, не описанную в таблице ответов.
11. **nit, дыры покрытия.** Добавить в сценарии: ключ `current` в таблицу
    отказов разбора конфига; кавычечные формы `{{> "../x.md"}}` и
    `{{> "/x.md"}}` в таблицу отказов линта; рендер динамического партиала
    с `@`-ссылкой (`{{> (concat "roles/" [role@] ".md")}}` в агентском
    файле); многострочный stdout в проверке `firstShellLine`.
