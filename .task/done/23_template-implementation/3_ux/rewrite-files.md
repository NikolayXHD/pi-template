# Правка зоны C — кнопка перерисовки файлов на диске

Требование @NikolayXHD (точно, не путать): последний пункт меню —
кнопка ПЕРЕРИСОВАТЬ ФАЙЛЫ НА ДИСКЕ. Ничего не применять к текущей
сессии, ничего не перечитывать, сессию не трогать. Применение (`apply`)
и перечитывание (`reload`) — не её дело; у применения в меню есть своя
кнопка, `apply` к этой приклеивать нельзя.

## Что сделать

1. Действие `applyAll` («apply all and reload») заменить на
   `rewriteFiles`: перегенерировать все целевые файлы на диске по текущим
   значениям переменных текущей сессии (секции как обычно: источники с
   точечными изменениями — точечно, прочие целиком; запись атомарная).
   Без `apply`: версии, notify, записи сессии и применённый контекст не
   трогаются. Без `reload`: сессия продолжает работать как есть.
   Пункт меню — последний: `rewrite files on disk`.
2. Кнопка `update current session context` (apply) остаётся отдельной,
   как есть.
3. Семантика версий: перерисовка не меняет appliedVersion; если целевые файлы
   ушли вперёд памяти сессии — это штатное «prompts are stale».
4. Тесты: probe (состав меню, порядок; сценарий: перерисовка обновляет
   целевые файлы, не меняет версий/записей сессии, не вызывает reload) и
   live/ux (после действия целевые файлы свежие, память сессии не тронута,
   Esc-петля на месте).
5. Проверка: `node probe.mjs`, `node live/typecheck.mjs`,
   `node live/ux.mjs` — зелёные. Отчёт — раздел «Перерисовка файлов» в
   `3_ux/report.md`. Коммиты не делать.
