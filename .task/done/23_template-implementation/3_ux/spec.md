# Спека C — UX и записи

Исполнитель: helper-cloud-fast. Зона C чек-листа issue.md. Рабочая копия —
`/home/kolia/git/pi-template`. API зоны B — `TemplateSession` (карта сессий
в `index.ts`, методы перечислены в `2_consumption/report.md`, раздел
«API для зоны C»).

## Результат

Единственная команда расширения `/template` с исчерпывающим меню,
статусная строка, записи `"var"` и resume. Других команд расширение не
даёт; листание `cycle`/Ctrl+R не переносится.

## Поведение

Источник истины — design.md задачи 23: разделы «UI», «Записи сессии и
resume», «Версии контекста сессии».

Меню `/template`:

- статус контекста сессии: промпты актуальны или устарели;
- значения переменных: для shell и env — возраст рассчитанного значения;
- смена сессионной переменной: только переопределяемые (не вычисляемые,
  не неявные `model`/`level`); пишется запись `customType: "var"`, payload
  `{name, value}`; изменение контекст НЕ применяет — только помечает
  устаревшим;
- перерасчёт указанной shell- или env-переменной;
- перерасчёт всех переменных;
- кнопка «обновить контекст текущей сессии» — применение (`apply()`).

Статусная строка: признак «промпты отстали» при расхождении версий;
сессионные переопределения — компактно.

Записи и resume: последнее значение каждой переменной по её записям
`"var"` сверх машинных `initial`; записи старого формата
(`customType: "role"`) игнорируются; старт новой сессии — машинные
значения, переопределения с нуля.

## Ловушки

- Стиль UI — как в старом расширении roles (pi-tui, меню с навигацией), но
  без его механики (`cycle`, Ctrl+R).
- Команда работает, когда сессия есть в карте `index.ts`; вне сессии или
  до её старта — понятное сообщение, не падение.
- Вычисляемые и неявные переменные в меню смены не предлагаются
  (read-only) — но с возрастом значений показываются.
- `"var"` — единственная запись расширения; другие `customType` не
  создавать. Payload строго `{name, value}`.
- Статусная строка — через `setStatus` API; индикаторы не плодить.
- Erasable TS, без `any`, импорты с `.ts`; новые публичные имена не
  вводить (уже согласованы `template.json`, `/template`, `"var"`, `@`,
  `model`/`level`).
- Коммиты не делать; `find`/`rg` запрещены; поиск — `git grep`, вне git —
  точечный `grep -rn`; toolTimeoutMs 120 с.

## Критерии приёмки

- `node probe.mjs` — все сценарии зелёные: новое, что тестируемо без pi
  (выбор переопределяемых переменных, запись и чтение записей `"var"`,
  игнор `"role"`, возраст значений).
- `tsc` — чисто.
- Живые проверки на pi SDK (как в зоне B): команда открывается, меню
  показывает статус и возраст значений, смена переменной помечает
  контекст устаревшим без применения, кнопка применяет, resume поднимает
  последние значения, запись `"role"` игнорируется.
- `report.md` (рядом со спекой): файлы, поведение, команды проверки и
  результаты, живые сценарии ручного прогона `/template`, вопросы и
  возражения.
