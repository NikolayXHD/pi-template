## Что сделать

1. **Esc — шаг назад.** Из режима редактирования значения переменной Esc
   возвращает в меню `/template`, а не закрывает интерфейс. Проверить и
   прочие диалоги меню тем же правилом: Esc — назад; полное закрытие —
   только из корня меню.
2. **Язык интерфейса — английский.** Все тексты, которые видит
   пользователь: пункты и заголовки меню, статусная строка, notify,
   предупреждения и ошибки в UI — включая сообщения `vars.ts` и `render.ts`
   (они уходят в предупреждения UI) — на английском, консистентно с pi.
   Русский остаётся в комментариях/докстрингах кода и в документации.
3. Тесты и живые скрипты — под новые тексты и поведение Esc.
