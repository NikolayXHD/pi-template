# Правка зоны C — «применить всё» с перечитыванием

Исполнитель: helper-cloud-fast (продолжение захода зоны C). Зона записи —
`/home/kolia/git/pi-template`; отчёт — раздел «Применить всё» в
`3_ux/report.md`. Коммиты не делать.

## Что сделать

В меню `/template` добавить действие «применить всё и перечитать»:

1. `apply()` — как существующая кнопка (актуальная → применённая, запись
   зеркал);
2. затем `reload()` — штатное перечитывание pi (командный контекст,
   `ExtensionCommandContext.reload`), после которого промпт-шаблоны и
   скилы берутся заново из зеркал текущей сессии.

Существующая кнопка «обновить контекст текущей сессии» остаётся как есть
(точечная замена секций, без перечитывания). Порядок пунктов меню — на
усмотрение, но не плодить новых команд.

## Поведение и границы (зафиксировать в отчёте)

- промпт-шаблоны (`prompts/**`) pi раскрывает из памяти загрузчика — без
  перечитывания их текст не обновляется; это и закрывает новое действие;
- скилы применяются и без перечитывания: описания — каждый ход, тела —
  чтением файла при вызове `/skill:` и read tool;
- `reload` заменяет рантайм расширения — состояние пересобирается из
  зеркал (уже работает, зона B); повторный `apply` после reload не нужен.

## Тесты и проверки

- `probe.mjs`: где возможно (модель меню: состав пунктов, порядок
  действий — apply до reload);
- живой прогон: после действия промпт-шаблон отдаёт текст с текущими
  переменными сессии (дополнить live-скрипт зоны C);
- `tsc`, `node probe.mjs` — зелёные.
