# Статус переменной в меню: актуальна / изменилась

Решение @NikolayXHD: в меню `/template` у каждой переменной видно
состояние относительно контекста, который уже в промпте. Источник данных
уже существует: в сессииуже хранится применённый вид и текущий вид — сравнением
получается статус без каких-либо новых вычислений.

## Что сделать

1. `session.ts`: публичный метод `appliedView()` — вид применённого
   контекста (копия), рядом с существующим `currentView()`.
2. `ui-model.ts`:
   - `MenuSession` получает метод `appliedView()`;
   - `VariableFacts` получает поле `applied: boolean` — значение
     переменной в текущем виде совпадает со значением применённого вида;
   - строка меню получает статус после значения: `fresh` — значение
     совпадает с применённым, `changed` — не совпадает (значит в промпте
     пока прежнее). Прежние маркеры (`computed, возраст`, `session
     override`) остаются.
3. `ui.ts`: TUI-меню и текстовый дайджест (без UI) показывают тот же
   статус.
4. `probe.mjs`: `fresh` до изменений; `changed` после сессионного
   переопределения; `changed` для вычислимой переменной после
   пересчёта с новым значением; `fresh` после применения.
5. `README.md` / `TESTING.md`: строка меню со статусом.
6. Отчёт — раздел «Variable status» в `3_ux/report.md`. Коммиты не
   делать. Проверки: `node probe.mjs`, `node live/typecheck.mjs`, живые
   скрипты.
