# Правки зоны C по кросс-ревью

Исполнитель: helper-cloud-fast (продолжение захода зоны C). Диспозиция по
`3_ux/cross-review.md`; код — `/home/kolia/git/pi-template`, отчёт —
дописывание раздела «Правки по кросс-ревью» в `3_ux/report.md`. Коммиты
не делать.

1. **C1, дискриминирующий тест игнора `"role"`.** Сценарий игнора записи
   `"role"` должен ловить снятие гейтов: добавить запись
   `customType: "role"` с валидным payload `{name, value}` (и запись без
   `customType`, но с валидной парой) — они обязаны игнорироваться; без
   этого снятие проверки `customType` сценарий не заметит.
2. **C2, непрогнанные ветки.** Ветки «ввод строки для переменной без
   `values`», «дайджест без UI», «сессия не найдена» закрыть живым
   прогоном (дополнить live-скрипт) и назвать в отчёте; если ветку нельзя
   воспроизвести — зафиксировать в остаточных рисках явно.
3. **C3, тест неявных.** Убрать искусственный `model`/`level` из
   `currentValues()` в сценарии: гарантия — отсутствие их в facts, тест
   должен опираться на это.
4. **C4, неявные вне TUI.** `model`/`level` показывать и в дайджесте/RPC как
   read-only — спека требует показа.
5. **C5, построение меню.** Построение пунктов меню — внутрь `try` (сбой
   не должен ронять команду, как и обещает комментарий).

Проверка: `node probe.mjs` (все зелёные), `tsc`, живой прогон. В живой
прогон добавить пункты из C2. Сомневаешься в толковании — ask через
supervisor.
