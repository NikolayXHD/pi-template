# 24 computed-variables-and-flash-rules

## Постановка (@NikolayXHD)

1. **Вычислимые переменные.** Шаблонная переменная `pi-template` должна
   вычисляться из других переменных. Пример: нужен управляемый список моделей
   с низким здравым смыслом — сейчас условие `model in (…)` с этим списком
   пишется в каждом месте шаблонов вручную; хочется объявить
   `{"is_flash": {"compute": "…"}}` в `template.json` в одном месте.

2. **Правила здравого смысла только для flash-моделей.** Разобрать правила
   поведения агента (глобальный `AGENTS.md` вместе с шаблонами и roles),
   похожие на хардкод компенсации отсутствия здравого смысла у лёгкой модели.
   Список — на согласование; показывать и обсуждать по одному, по протоколу
   интервью.

Часть 2 зависит от части 1: перенос правил под `is_flash` требует механизма
из части 1 (сейчас список моделей захардкожен в трёх файлах).
