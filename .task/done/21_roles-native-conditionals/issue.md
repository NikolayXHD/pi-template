# 21 — roles: условные сниппеты штатными механизмами Mustache

## Контекст

Задача 20 дала условным сниппетам собственную алгебру: записи
`template_variables` с областью «модель + уровень мышления», сужение через
`flags`, обязательная запись `default`, правила смешивания знаков, обнаружение
конфликтов записей, сбор имён секций для сопоставления. @NikolayXHD предлагает
выкинуть всё это и опираться на штатные механизмы Mustache: сниппет, который
должен быть условным, оборачивает своё содержимое в секцию, смотрящую на
текущую пару «модель, уровень» — например `{{#model.mimo}}...{{/model.mimo}}`
или `{{^level.high}}...{{/level.high}}`. Сниппет без обёртки — безусловный.
View строится из контекста хода, никаких пользовательских отображений.

## Что это убирает (оценка)

- `template_variables` целиком: scope, flags, алгебра списков, запись
  `default`, конфликты, соответствующие предупреждения.
- Сбор имён секций и сопоставление с флагами.
- Выбор записи (`valueForEntry`/`matchEntries`) и смену записи как
  единицу наблюдения.
- Примерно половину сценариев probe (вся таблица отвержений конфига,
  алгебра, конфликты).

## Что остаётся

- `roles.json` минимальный: `default`, `cycle`.
- Партиалы `{{> файл}}`, рендер, горячее применение правок входов.
- Роль, Ctrl+R, `/role`, событие.
